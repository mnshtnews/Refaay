# بوت تيليجرام — التنبيهات الذكية + القوائم + التقارير + الفواتير

## الإعداد (متغيرات البيئة)
| المتغير | المعنى |
|---|---|
| `TELEGRAM_BOT_TOKEN` / `TELEGRAM_CHAT_ID` | موجودين (البوت + الجروب). الجروب ده هو الوحيد المسموح له يستخدم البوت. |
| `TELEGRAM_ADMIN_IDS` | **جديد**: أرقام تيليجرام للأدمن (مفصولة بفاصلة) مثال `123456789,987654321`. أي حد غيرهم = عضو عادي. |
| `TELEGRAM_ACT_AS_USERNAME` | اختياري: اسم حساب النظام اللي بتتسجل باسمه الفواتير من البوت (الافتراضي: أول مالك/أدمن نشط). |
| `STOCK_ALERT_INTERVAL_SEC` | اختياري: فترة فحص المخزون (الافتراضي 180 ثانية). |
| `TELEGRAM_BOT_ENABLED=0` | اختياري: لإيقاف البوت التفاعلي (التنبيهات الذكية تفضل شغالة). |

**إزاي تعرف رقم الأدمن:** اكتب `/myid` للبوت (في الجروب أو الخاص) هيرد برقمك.

**في BotFather:** يفضّل `/setprivacy` → Disable، عشان البوت يشوف ردود الأدمن النصية في الجروب (أو الأدمن يستخدم البوت في الخاص، وده أنضف).

## التنبيهات (حل مشكلة الـ 2000 رسالة)
- بتتبعت **عند التغيّر فقط**: سليم→قارب ينفد، سليم→نفد، قارب→نفد. مفيش تكرار يومي.
- كل التغييرات في نفس الدورة بتتجمع في رسالة (حد أقصى 3 رسائل لكل دورة + "و N منتج آخر" + زرار تقرير PDF).
- أول تشغيل بعد النشر: المنتجات الناقصة حاليًا بتتسجل كمعروفة **من غير إرسال** (مفيش طوفان).
- لو منتج اتوفّر تاني وبعدين نزل = تنبيه جديد.

## الصلاحيات
| | عضو الجروب | الأدمن |
|---|---|---|
| تقرير نفد / قارب / الاتنين (PDF) | ✅ | ✅ |
| كشف بواقي العملاء (PDF) | ✅ | ✅ |
| مستحقات الموردين، استعلام منتج، ملخص اليوم، Excel، إعدادات التنبيهات | ❌ | ✅ |
| فاتورة جديدة (خطوة بخطوة، تتنفّذ عبر API النظام بنفس قواعده) | ❌ | ✅ |
الصلاحية بتتفحص على السيرفر مع كل ضغطة زرار. أي جروب/محادثة تانية = البوت يتجاهلها.

## الكلام مع البوت في الجروب (للأدمن والأعضاء)
البوت بيفهم عربي عادي، بس لازم تكلّمه صراحةً عشان ما يردش على كل رسايل الجروب:
- منشن: `@اسم_البوت المنتجات اللي نفدت` — أو ابدأ الرسالة بـ «بوت …» — أو اعمل Reply على رسالة من البوت.
- أمثلة: «بواقي العملاء» · «المنتجات اللي قربت تخلص» · «نفدت وقاربت» · «سعر نجفة كريستال» (أدمن) · «مستحقات الموردين» (أدمن) · «ملخص النهاردة» (أدمن) · «فاتورة جديدة» (أدمن).
- العضو العادي بيطلب حاجة للأدمن = رد مهذّب "للأدمن فقط" ومفيش تنفيذ.
- لو الأدمن كاتب كـ"أدمن مجهول" (Remain Anonymous) تيليجرام مابيبعتش رقمه فالبوت مش هيتعرف عليه → أوقف الخيار ده من صلاحياتك.
- `/myid` بيوريك رقمك ودورك عند البوت (أدمن/عضو) — أول حاجة تجرّبها لو البوت مش بيرد كأدمن.
